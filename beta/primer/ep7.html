Workflows: models and tools orchestrated through predefined code paths. Agents: models dynamically direct their own processes and tool usage.vendor definition, Anthropic Dec 2024

Part 4: What the evidence says about agents

tau-bench: GPT-4o with function calling about 61 percent of retail tasks and about 35 percent of airline tasks on one try; about 25 percent of retail tasks if it must succeed on all eight tries.research result, 2024 models

Limits: LLM-simulated user, two domains, 2024 models.research description

pass@k rises with more tries; pass^k falls. A 75 percent per-try rate gives about 42 percent over three tries in a row.vendor guidance, Anthropic Jan 2026

Part 5: How agents fail

tau-bench failures: complex reasoning over databases, ad hoc policies, compound requests.research result

Indirect prompt injection: applications blur data and instructions, so text the agent reads can act as instructions.research claim, Greshake et al. 2023

OWASP says it is unclear whether foolproof prevention exists, and that retrieval and fine-tuning do not fully mitigate it.industry guidance

The one idea

A language model only produces text. It 'uses a tool' when it writes a tool request as text, a program runs it, and the result returns to the model's desk. In Anthropic's vocabulary, a workflow follows a path the programmer set in advance and an agent chooses its own path in a loop. The same guide recommends the simplest design that works. A 2024 benchmark found agents can succeed once and still be inconsistent, so repeat runs matter. Text an agent reads can carry instructions, so autonomy is a dial to set deliberately.

Key terms

Tool call. A request the model writes as text; ordinary software runs it.vendor guidance

Workflow. Models and tools orchestrated through predefined code paths.Anthropic

Agent. A system where the model dynamically directs its own process and tool use.Anthropic

ReAct. Interleaving reasoning steps and actions.Yao et al. 2022

pass@k. Chance of at least one success in k tries.Anthropic 2026

pass^k. Chance that all k tries succeed.tau-bench; Anthropic 2026

Indirect prompt injection. Instructions placed in content the model reads.Greshake et al.; OWASP

Worked scenario (invented)

An online shop (invented) handles refund emails. A workflow labels the email, extracts the order number, looks it up in code and drafts a reply from policy. It handles common cases cheaply and hands odd ones to a person. An agent would only be considered if requests were very varied, its tools were limited, a person approved refunds above a small amount, and it passed many repeated sandbox runs.invented illustration

Decision card

  1. Could a fixed path do this?
  2. What can the tools change in the world?
  3. Who approves consequential actions?
  4. Has it been run many times in a sandbox, and how often does it succeed every time?
  5. What outside text does it read, and what could that text tell it to do?

Counterpoints and limits

  • Anthropic's guide is vendor advice, not a controlled study, and notes tooling has changed.vendor
  • tau-bench numbers are from 2024 models and a simulated user.research
  • The four-position dial is our model, not a standard.our interpretation
  • We did not verify whether OWASP lists prompt injection first on the full list, only that its entry is LLM01:2025.open item

Try it yourself

Pick a task you do weekly. Write it as a fixed list of steps. Mark which step needs judgment. If only one does, that is a workflow with one model call, not an agent.

Quiz

  1. What does a model actually produce when it 'uses a tool'?
    AnswerText: a structured request that a separate program reads and runs.
  2. How does Anthropic's guide distinguish workflows and agents?
    AnswerIn workflows the paths are predefined in code; in agents the model dynamically directs its own process and tool use.
  3. What does pass^k measure?
    AnswerThe probability that all k trials succeed.
  4. Why can a web page be an attack on an agent?
    AnswerText the model reads can act as instructions: applications blur data and instructions (indirect prompt injection).
